# Contributing to Ragnar's Den

Thanks for your interest in Ragnar's Den. It's a personal project made by Hunter & Kayn, and the code is not open source (see [LICENSE](LICENSE)).

## Bug reports are welcome

If something on the sheet is wrong, a rule doesn't match the book, or the app breaks, please [open an issue](../../issues/new/choose) using the bug report form. The more detail you give (class, level, 2014 or 2024 rules, and the steps that led to the problem), the faster it can be fixed.

Rules questions are welcome too. If you think a feature, spell or monster doesn't match the published book, say which book and page.

## Pull requests are not accepted

Please don't open pull requests. Every change is checked against the published books before it goes in, and the license doesn't allow outside changes to the code. Pull requests will be closed without being merged. Open an issue instead and describe what you'd like to see.

## Security

If you find a security problem, please report it privately through the repository's **Security** tab (Report a vulnerability) instead of opening a public issue.
